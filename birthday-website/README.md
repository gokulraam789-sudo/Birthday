# Birthday Website

Open `config.js` to change the wish, letter, gift message, password and your name.

## Run in GitHub Codespaces
```
unzip birthday-website.zip
cd birthday-website
python3 -m http.server 8000
```
Codespaces will pop up a notification for port 8000. Click "Open in Browser".
(Or right-click `index.html` and choose "Open with Live Server" if that extension is installed.)
